Unzip this package and upload all files directly to the top level of your repository, alongside index.html. Do not upload the ZIP itself. No subfolders or build step are needed.

Keep the same site address to retain browser-saved progress. Existing question history and flashcard scheduling use the same storage key. Named practice sets are included in Progress > Export backup.
