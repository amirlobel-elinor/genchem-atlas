Gen Chem Atlas — INTERACTIVE CHEMISTRY EDITION

Upload every file in this ZIP directly to the root of your GitHub repository.
There are no nested folders. index.html is the website entry point.

UPDATING YOUR GITHUB SITE
1. Unzip this package on your computer.
2. Open your repository, choose Add file > Upload files.
3. Drag all nine extracted files into the upload area (not the ZIP).
4. Commit the changes. Files with matching names replace the previous versions.
5. If Pages is already configured, wait for its deployment to finish, then refresh.
   For a new site: Settings > Pages > Deploy from a branch > main > / (root).
6. If the old app appears, reload with your browser cache bypassed.

WHAT IS NEW
- A categorized Chemistry games directory with all ten activities.
- Visible topic buttons with chapter choices for larger topic collections.
- Manual Lewis structures: count valence electrons, then place every bond and pair.
- Resonance lab: electron-pushing arrows, contributors, and resonance hybrids.
- Shape lab: rotatable 3D models and electron vs. molecular geometry.
- Compact suggestion box below the sidebar utilities.
- Section-specific ion, molecule, orbital, equation, and reaction-balancing challenges.
- Concept rounds, five-question problem trails, and reversible recall decks.
- Colorful chapter and game menus with shorter instructions and optional help.
- Sidebar shortcuts for every chemistry game, with visible topic buttons inside each.
- Settings at the bottom of the sidebar; dark mode is available inside Settings.
- Levels, XP, badges, and progress dashboards removed.
- Lectures 26–28 added to Chapter 8, with PDF page references.
- Existing chapter grouping, saved practice sets, exam practice, and sources retained.

SUGGESTIONS
The Suggestion box below Settings asks: What would help you study?
Choose a study idea, feature request, or problem, then write your message.
Open email draft addresses it to amirlobe@usc.edu; press Send in your email app.
This static app does not send email automatically or use an external form service.
If no email app opens, use Copy feedback and paste it into webmail.
Feedback text remains available while this page is open; it is not saved in backups.

SAVED DATA
The app runs without a build step or account. Core study content works offline.
OpenStax reading links require the internet.
Saved data stays in the browser on the same site address. The existing storage
key is preserved. Export a backup from Settings before changing browsers,
clearing browser data, or moving to another site address. Import restores it.
Old backups remain compatible for answers, flashcards, and saved practice sets.
Unfinished problem sets are saved. Interactive lab arrangements are for the
current visit.

SCIENCE & SCOPE
Original exercises follow the supplied lectures and exams and map to Chemistry 2e.
Chapter 9 is still exam-supported; Chapter 8 now includes Lectures 26–28.
The Lewis builder starts with unconnected atoms on a fixed scaffold.
Resonance exercises use equivalent contributors on fixed atom frameworks.
The shape models are idealized VSEPR teaching models, not measured geometries.
Orbital energy spacing and molecule sketches are schematic. Any course-specific
MO order is displayed. Hints/solutions are marked as assisted practice.
