GEN CHEM ATLAS — INTERACTIVE CHEMISTRY EDITION

Upload every file in this ZIP directly to the root of your GitHub repository.
There are no nested folders. index.html is the website entry point.

UPDATING YOUR GITHUB SITE
1. Unzip this package on your computer.
2. Open your repository, choose Add file > Upload files.
3. Drag all nine extracted files into the upload area (not the ZIP).
4. Commit the changes. Files with matching names replace the previous versions.
5. If Pages is already configured, wait for its deployment to finish, then refresh.
   For a new site: Settings > Pages > Deploy from a branch > main > / (root).
6. If the old app appears, reload with your browser cache bypassed.

SAVED DATA
The app runs without a build step or account. Core study content works offline.
OpenStax reading links require the internet.
Saved data stays in the browser on the same site address. The existing storage
key is preserved. Export a backup from Settings before changing browsers,
clearing browser data, or moving to another site address. Import restores it.
Old backups remain compatible for answers, flashcards, and saved practice sets.
Unfinished problem sets are saved. Interactive lab arrangements are for the
current visit.

SCIENCE & SCOPE
Original exercises follow the supplied lectures and exams and map to Chemistry 2e.
Chapter 9 is still exam-supported; Chapter 8 now includes Lectures 26–28.
The molecule builder uses fixed Lewis scaffolds, not an arbitrary 3D editor.
Orbital energy spacing and molecule sketches are schematic. Any course-specific
MO order is displayed. Hints/solutions are marked as assisted practice.
